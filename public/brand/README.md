# Tripwire identity

The site uses the three-bar vector mark with a live Tripwire wordmark.
Use `src/components/Logo.tsx` in the application; its text follows the theme.

| Asset | Use |
| --- | --- |
| `tripwire-mark.svg` | Standalone vector mark |
| `tripwire-social.png` | 1200 × 630 social card |
| `tripwire-social.svg` | Editable source for the social card |
| `../favicon.svg` | Browser icon |

The wordmark and old product routes were retired on 11 October 2026. Historical
social artwork in `docs/social/` is not part of the deployed public directory.
