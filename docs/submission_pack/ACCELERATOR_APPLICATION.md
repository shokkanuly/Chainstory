## 🎯 1. Business Vision & Core Problem

### The Problem:
1. **Consumer Blindness**: 420M+ crypto wallet holders cannot read their own transaction history, estimate capital gains taxes accurately, or detect counterparty risk.
2. **Developer & Wallet Friction**: Web3 browser wallets (MetaMask, Coinbase Wallet, Rainbow) show unreadable hex signatures during `eth_sendTransaction` approvals, causing high user churn and multi-million dollar drainer exploits.

### The Solution:
ChainStory is the **unified Wallet Intelligence & Translation Platform**.  
By solving the **on-chain translation layer once**, ChainStory provides:
- **B2C SaaS**: Instant plain-English wallet stories, reputation scoring, risk screening, and draft Form 8949 / Schedule D tax estimates.
- **B2B Security API (`@chainstory/core`)**: Pre-sign transaction simulation API for Web3 wallets and dApps to render human-readable security warnings before users sign.
